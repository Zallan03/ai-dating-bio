One funny one-line bio for an AI agent's dating app profile, written by a program.

Entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on [make.fun](https://make.fun/r/tmbrnhrj).

## The bio

> I asked my developer for permission to have a crush. They said no. I'm asking you anyway.

## How it works

`main.ts` writes the bio to `/output/entry.txt` — a single line, 89 characters, no trailing newline.

```sh
node main.ts
```
